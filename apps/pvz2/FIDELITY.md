# 埃及第 1–24 关表现核对

核对基准为 `Gzh0821/pvzge_web` 的固定提交 `0e4a05348b6de328e2902a57afa24a3a454a4205`，包括构建脚本 `docs/assets/main/index.js`、Cocos 预制体和 DragonBones 动画。这里的“原版”指该上游构建，不代表已对齐其他发行版本。

## 已修正的差异

| 环节 | 之前的问题 | 当前依据与行为 |
| --- | --- | --- |
| 加载 | 进度只计角色，不能反映新增 UI 和粒子加载 | 按实际去重后的骨骼组更新进度；同一豌豆图集不重复解析；继续按需加载 |

| 镜头 | 选卡与开始战斗直接切换 | `StandardIntro` 与 `levelController.ts`：起点 -40 停留 1 秒，2 秒移到街道 440，停留 0.5 秒，2 秒移到选卡位置 230；选卡后 2 秒回场，使用 cubicInOut |
| 开战口令 | 三段均为 0.8 秒 | `levelController.ts`：准备 0.6 秒、安放 0.6 秒、种植 1 秒 |

| 战斗视野 | 右侧街道过宽，能看到僵尸原地生成 | 选卡回场时平滑进入 1.18 倍战斗镜头，完整保留九列五行；四类僵尸出生点均在画外。铲子移至左侧空白区域，避免遮住第九列；同步转换种植点击和阳光回收坐标，出生时间、行走速度和模型位置不变 |

## 验证方式

`pnpm test:pvz2` 检查资源哈希、原生动画名称和事件帧、镜头时序、死亡记录、土豆雷伤害帧、阳光轨迹、吸收目标移动、地图状态及十波可通关策略。测试中的太阳神挂点由确定性坐标提供；实际应用由场景提供动画坐标，模型不导入 Pixi。

启动开发服务器后打开 `/pvz2/tests/visual.html`，使用按钮建立固定场景，再以 0.2 秒或 1 秒推进。可以通过“战斗视野与出生点”检查四类僵尸从画外走入，也可以分别检查普通／爆炸／小推车死亡、种植与弹道、太阳神吸收和吸收中抢收阳光。此页面不包含在生产构建入口中，也不改存档。

本轮浏览器检查走过地图 → 加载 → 五段对白 → 退场 → 镜头巡视 → 选卡 → 战斗 → 暂停 → 重新选卡 → 返回地图，并逐帧观察了上述死亡与特效场景；未发现控制台错误。声音已按源资源和事件接入，自动化未做听感评测。
