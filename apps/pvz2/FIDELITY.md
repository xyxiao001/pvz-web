# 首关表现核对

核对基准为 `Gzh0821/pvzge_web` 的固定提交 `0e4a05348b6de328e2902a57afa24a3a454a4205`，包括构建脚本 `docs/assets/main/index.js`、Cocos 预制体和 DragonBones 动画。这里的“原版”指该上游构建，不代表已对齐其他发行版本。

## 已修正的差异

| 环节 | 之前的问题 | 当前依据与行为 |
| --- | --- | --- |
| 加载 | 进度只计角色，不能反映新增 UI 和粒子加载 | 按实际去重后的骨骼组更新进度；同一豌豆图集不重复解析；继续按需加载 |
| NPC | 直接出现、仅播放说话动作，缺少语音与退场 | `NPC.ts`、`NPC_Controller.ts`、`CrazyDave.ts`、`Winnie.ts`：Enter → 分句动作与语音 → Exit；中文图形长度系数 3.1，按 SAY/PLAYFUL 选声音；温妮车声跟随动画事件 |
| 镜头 | 选卡与开始战斗直接切换 | `StandardIntro` 与 `levelController.ts`：起点 -40 停留 1 秒，2 秒移到街道 440，停留 0.5 秒，2 秒移到选卡位置 230；选卡后 2 秒回场，使用 cubicInOut |
| 开战口令 | 三段均为 0.8 秒 | `levelController.ts`：准备 0.6 秒、安放 0.6 秒、种植 1 秒 |
| 普通死亡 | 从模型移除后仅做 0.3 秒透明渐隐 | `Zombie.ts`、`BodyGrouper.ts`、`Character.ts`：掉头、断臂槽位控制、独立碎片、原生 Death 动画与倒地音效，die 事件后淡出 0.5 秒 |
| 死亡时序 | 所有僵尸共用消失时间 | 30 fps：木乃伊 fall=28、die=40；旗帜 fall=45、die=57；太阳神 fall=45、die=67。终止帧上的事件同样读取 |
| 特殊死亡 | 爆炸、小推车和普通击杀表现相同 | 土豆雷击杀后身体直接移除、头部继续抛出；小推车在 0.5 秒内旋转并压扁身体 |
| 结算 | 最后一只僵尸死亡后立即弹窗 | 死亡记录保留给渲染器，等待倒地、淡出与碎片演出完成；模型内仍立即移除死亡目标 |
| 路障挂点 | 帽子旋转歪到脸侧 | 读取 `armorSOCKET` 前更新骨骼全局变换；脱落路障保留损伤外观 |
| 土豆雷 | 蓄满后立即造成伤害 | Grow 第 18 帧激活，Charging 第 14 帧爆炸、第 15 帧移除，使用 ExplosionSpudow 原始粒子 |
| 种植与弹道 | 简单几何形状代替特效 | 原始泥土 Plant/Remove、豌豆弹体和三套命中动画 |
| 阳光 | 匀速垂直移动，点击立即消失 | `Sunflower.ts`、`dropping.ts`：生产阳光抛出，落地后开始 7 秒停留与 0.5 秒淡出；收集时 1 秒 quadOut 飞向计数器、0.2 秒缩小 |
| 太阳神 | 仅吸收近处阳光，立即从画面移除 | `EgyptRaZombie.ts`、`sun.ts`：按 250 上限占用庭院阳光，AbsorbStart/Absorbing/AbsorbEnd，三次 0.5 秒牵引与 0.3 秒间隔，阳光 N-R/Red/R-N；目标通过场景接口读取原预制体绑定的 `rays` 骨骼位置 |
| 卡片比例与清晰度 | 顶部 flex 拉伸卡片，UI 截图再次有损压缩，背景缩小一半 | 卡片保持 238∶150；UI 与头像以 2 倍分辨率导出 PNG；庭院保留 3948×1536 原图尺寸，渲染时保持既有世界坐标 |
| 战斗视野 | 右侧街道过宽，能看到僵尸原地生成 | 选卡回场时平滑进入 1.18 倍战斗镜头，完整保留九列五行；四类僵尸出生点均在画外。铲子移至左侧空白区域，避免遮住第九列；同步转换种植点击和阳光回收坐标，出生时间、行走速度和模型位置不变 |
| 字体与计数器 | 对白部分字形回退，黑底阳光数字为深色 | 补齐首关字形子集；SunCount 使用原标签的白色文字 |

## 验证方式

`pnpm test:pvz2` 检查资源哈希、原生动画名称和事件帧、镜头时序、死亡记录、土豆雷伤害帧、阳光轨迹、吸收目标移动、地图状态及十波可通关策略。测试中的太阳神挂点由确定性坐标提供；实际应用由场景提供动画坐标，模型不导入 Pixi。

启动开发服务器后打开 `/pvz2/tests/visual.html`，使用按钮建立固定场景，再以 0.2 秒或 1 秒推进。可以通过“战斗视野与出生点”检查四类僵尸从画外走入，也可以分别检查普通／爆炸／小推车死亡、种植与弹道、太阳神吸收和吸收中抢收阳光。此页面不包含在生产构建入口中，也不改存档。

本轮浏览器检查走过地图 → 加载 → 五段对白 → 退场 → 镜头巡视 → 选卡 → 战斗 → 暂停 → 重新选卡 → 返回地图，并逐帧观察了上述死亡与特效场景；未发现控制台错误。声音已按源资源和事件接入，自动化未做听感评测。

## 尚未达到逐帧对齐的部分

- 场景仍使用 1200×700 模拟坐标，UI 仍为比例布局；需要继续对照原引擎的坐标、缩放、对话框和卡片排版。
- 太阳神死亡返还阳光仍合并为一颗，未实现原版逐颗散射、减速与吸收末端缩小。
- 僵尸出生随机位置、步速变化、小推车入场及完整战斗环境音仍待接入。
- 加载页沿用上一轮的埃及主题设计，尚未宣称与上游加载页逐帧一致；埃及前段返图已接入节点完成、道路推进、下一节点开启及原音效，第 2、3 关后的植物奖励通过独立测试场景核对；世界解锁、后段礼盒与奖杯仍按 README 中的范围处理。

这些差异继续在第一关基础上解决，不据此开放后续关卡。
