# PVZ2 · 世界地图

独立的 TypeScript / PixiJS 应用，入口为 `/pvz2/`。使用原生世界选择与地图选关外层，埃及第 1–11 关已接入，可按原地图推进进入战斗。

## 当前外层

- 使用上游世界浮岛、背景、关卡节点、奖励卡、升级奖杯、路径、按钮、字体、音乐和点击音效。
- 导出 13 个主世界的原始坐标、远景视差、主线与分支连接，保留另外两个不可进入的世界图标。
- 世界选择支持点选、横向滑动、滚轮和方向键；地图支持拖动、惯性、滚轮、边缘箭头及关卡点击。
- 埃及第 1–11 关接入对应对白、选卡／传送带／道具战斗流程；其他关卡显示待接入状态。世界介绍中的“查看地图”仅供预览，不消耗钥匙、不解锁世界或授予奖励。
- 商店、图鉴、花园、小游戏与经济系统未接入，顶部原版入口暂不可用，资源栏为零。设置提供独立的音乐、音效音量，并与二代战斗共享设置。

还原基准是上游的地图布局、美术、动画与导航交互。当前不是完整复刻：世界介绍已接入原生横幅和本世界植物卡片；设置采用原生窗口美术。埃及前段已接入通关节点、道路推进和植物奖励状态；完整世界解锁演出、皮纳塔开箱、无尽模式、小游戏和第 7 关以后的战斗尚待接入。无尽入口按上游未解锁状态呈现。上游沙滩保龄球骨骼本身缺少 `_ro0/_ro1/_ro2` 子骨骼，冰窟、古城部分骨骼有重复名称，保留原数据；未伪造这些动画。

## 与 PVZ1 的边界

PVZ1 保留在根项目，PVZ2 的代码、素材、依赖声明、测试和构建配置均在本目录。两者不导入对方的游戏逻辑、渲染器和资源，复用固定步长模拟、模型与渲染分离、按需加载、纹理预上传等设计。游戏之间通过页面跳转切换。

`pvz2-web:<关卡 ID>-complete` 分别保存各关通关记录，首关仍使用原来的 `pvz2-web:egypt1-complete`。`pvz2-web:map-rewards` 记录已获得的地图奖励，`pvz2-web:pending-map-completion` 记录待播放的返图流程。`pvz2-web:campaign-rewards` 记录道具奖杯、幼苗、皮纳塔、便条、世界钥匙和金币袋的首通领取记录。`pvz2-web:world-navigation` 保存世界选择及各地图浏览位置，`pvz2-web:audio` 保存二代音量。不会读写 PVZ1 存档。

PVZ2 在 PVZ1 的 Service Worker 清单生成后才拼入发布目录，不参与一代离线下载；当前没有自己的 Service Worker。

## 运行与验证

在仓库根目录执行：

```sh
pnpm install
pnpm dev             # PVZ1 :5173；PVZ2 :5174，经 :5173/pvz2/ 代理访问
pnpm dev:pvz2        # 单独启动 PVZ2，访问 http://127.0.0.1:5174/pvz2/
pnpm test:pvz2
pnpm build:pvz2      # 独立输出 apps/pvz2/dist/
pnpm build           # 组合到 dist/ 与 dist/pvz2/
```

`pnpm test` 运行 PVZ1 测试。根目录 `pnpm preview` 预览组合构建。地图测试覆盖原始连线、解锁状态、浏览边界、动画资源引用及输出哈希；战斗测试保留原有十波通关与植物技能验证。

## 加载与后续接关

`src/shell/controller.ts` 管导航与 DOM 交互，`renderer.ts` 管独立动画时钟、相机和 Pixi 绘制，`navigation.ts` 管原地图节点状态与关卡路由。`progression.ts` 管通关和奖励状态，以及原版半秒间隔的返图事件。`game/levels.ts` 登记已迁移关卡的资源、名称、选卡范围与首通奖励；选卡在每次进入时读取已获得植物。新增战斗入口时同步扩展 `LEVEL_ROUTES` 与关卡配置，战斗模型和资源仍需逐关迁移。

首屏加载世界选择及共用 UI；进入世界后才请求该地图的 JSON、骨骼和 WebP 图集。骨骼两组并发加载并预上传纹理，离开地图释放其图集；远处的前景实例按可见范围创建和释放。音乐在首次交互时请求。原字体按外层、已迁移关卡 UI 和对白文案提取为约 172 KB WOFF2，保持原字形。

埃及第 2–11 关的 campaign 素材共约 14.69 MB，按关卡和可用植物加载相应图集；夜间庭院仅第 4、5、7、8 关加载。退出战斗时销毁渲染器、动画时钟和事件监听，纹理仍复用资源缓存。道具图标只在第 5 关加载，卡片仅生成本局可用植物及首通奖励。

13 个世界的外层资源合计约 43.6 MB（文件大小，含音乐，不含脚本和现有约 5.05 MB 战斗资源），不会一次全部下载。新增世界介绍资源约 0.93 MB，在打开介绍时加载；首关 UI、角色、粒子和音效约 5.05 MB，在进入战斗时加载。地图和首关战斗分别使用动画时钟；进入战斗时停止地图，返回时恢复。战斗代码与样式动态导入，样式限定在 `.battle-app` 内。

## 埃及第 1 关

流程为首次角色入场与对白 → 角色退场 → 镜头浏览庭院和街道 → 四种可用植物的自由选卡 → 镜头回场 → 准备／安放／种植 → 十波战斗 → 首次地图奖励 → 返回地图。再次进入已完成关卡会跳过首次对白和首次奖励。暂停可调整音量、重新选卡或返回地图；战斗支持二倍速。通关领取奖励后，第 2 关节点按原地图连线开放。

使用原始戴夫、温妮、植物、僵尸、阳光、小推车骨骼，卡片、阳光槽、铲子、按钮和进度条来自原资源。卡片复用地图已加载的图集。四种植物可选择、取消和重新排列，未选择的植物不能在本局种植。

已修正原型规则：初始阳光 50，初始能量豆 0；天空阳光采用原模块的 2 秒首次延迟与 6–12 秒递增随机间隔；首波等待 15 秒并保留进场延迟；后续按本波身体血量和 25–30 秒倒计时触发，保留 4–5 秒最短波间隔；第 10 波额外生成原引擎的旗帜僵尸。移除了每击败 6 只僵尸送能量豆的自制规则。

本轮已接入原版镜头时序、NPC 入退场和分句语音、断臂／掉头／倒地／淡出、小推车碾压、种植与铲除泥土、豌豆弹体与命中、土豆雷出土和爆炸。伤害与移除读取骨骼事件帧；最后一只僵尸的死亡演出完成后才显示结算。阳光支持向日葵抛出、落地计时、飞向计数器，以及太阳神的分段吸收、变色和法杖挂点追踪。路障帽子使用更新后的骨骼变换，修复朝向错误。

这仍不能视为逐帧复刻。待继续核对：太阳神返还阳光的逐颗散射与收尾缩放、僵尸出生随机偏移和步速变化、小推车入场演出、完整战斗环境音，以及 DOM 界面的原始布局。庭院背景保留 3948×1536 原始分辨率（约 1.47 MB，仅进关时加载），卡片按原比例显示，UI 截图使用 2 倍分辨率 PNG。战斗镜头收紧到完整草坪，选卡仍保留街道预览。当前战场沿用 1200×700 的模拟坐标；镜头时间和事件帧取自原版，但场景、角色和 UI 的像素位置仍需逐项比对。世界地图奖励已接通，完整经济掉落及能量豆功能解锁界面未接入。详细基准和复查步骤见 [FIDELITY.md](./FIDELITY.md)。

## 来源与可重复提取

来源：[PvZ2 Gardendless](https://github.com/Gzh0821/pvzge_web)，固定提交 `0e4a05348b6de328e2902a57afa24a3a454a4205`。从 Cocos 构建产物读取场景、嵌套预制体、属性覆盖与 DragonBones 资源，在独立应用中实现导航和渲染；无需运行其 Cocos、Bullet、Spine WASM，也没有还原原始 TypeScript 工程。

`asset-provenance.json`、`shell-provenance.json`、`battle-provenance.json`、`window-provenance.json`、`progression-provenance.json` 和 `campaign-provenance.json` 记录各资源组的输入／输出 SHA-256。`UPSTREAM-LICENSE` 保留仓库许可证文本，不代表对第三方美术、音乐另行授权。

```sh
# 战斗资源需要 Pillow；地图额外需要 fonttools 和 brotli。
python3 tools/pvz2-assets/extract.py
python3 tools/pvz2-assets/extract-shell.py
python3 tools/pvz2-assets/extract-world-window.py
python3 tools/pvz2-assets/extract-first-level.py
python3 tools/pvz2-assets/extract-progression.py
python3 tools/pvz2-assets/extract-egypt-campaign.py
```

下载及纹理编码缓存放在忽略目录 `artifacts/pvz2-source/`。传送门引用普通关卡的两套光线子骨骼，提取时显式合并这一依赖；其余骨骼保留上游结构。字体子集取自世界名称、介绍、当前控制器文案和首关对白，修改文案后重新执行地图提取脚本。

## 埃及地图通关流程

首次通关返回地图时，依次播放原节点 `Finish`、道路 `Push`、下一节点 `Open` 及对应音效，演出时长取自原骨骼。重玩不重复播放首次解锁，也不重复发奖。旧首关记录沿用原存储键。

第 2、3、5 关后的卷心菜投手、回旋镖射手、冰冻生菜奖励已接入状态与原生植物展示，奖励节点先记入已获得植物，再继续开启后续关卡。新增植物骨骼在对应战斗、奖励演出或植物展示时加载。正式战斗入口开放第 1–11 关。

开发时打开 `/pvz2/tests/map-visual.html` 可依次核对前三关的返图演出、奖励持久化接口与重新打开地图后的状态。页面使用独立内存存档，不修改游戏存档；自动化测试另外覆盖存储重建后的读取。素材由 `tools/pvz2-assets/extract-progression.py` 从固定上游版本提取，来源与输出哈希见 `progression-provenance.json`。
