# PVZ2 · 世界地图

独立的 TypeScript / PixiJS 应用，入口为 `/pvz2/`。当前先搭建原生世界选择与地图选关外层，后续逐关移植战斗。原先自制的埃及封面已替换，现有埃及首关仍作为战斗原型接在地图第 1 关。

## 当前外层

- 使用上游世界浮岛、背景、关卡节点、奖励卡、升级奖杯、路径、按钮、字体、音乐和点击音效。
- 导出 13 个主世界的原始坐标、远景视差、主线与分支连接，保留另外两个不可进入的世界图标。
- 世界选择支持点选、横向滑动、滚轮和方向键；地图支持拖动、惯性、滚轮、边缘箭头及关卡点击。
- 埃及第 1 关接入现有原型；其他关卡显示待接入状态。世界介绍中的“查看地图”仅供预览，不消耗钥匙、不解锁世界或授予奖励。
- 商店、图鉴、花园、小游戏与经济系统未接入，顶部原版入口暂不可用，资源栏为零。设置仅提供声音开关和返回一代。

还原基准是上游的地图布局、美术、动画与导航交互。当前不是完整复刻：世界介绍和设置窗口的内容为移植阶段的精简版本；完整世界解锁演出、奖励领取、无尽模式、小游戏和各关战斗尚待接入。无尽入口按上游未解锁状态呈现。上游沙滩保龄球骨骼本身缺少 `_ro0/_ro1/_ro2` 子骨骼，冰窟、古城部分骨骼有重复名称，保留原数据；未伪造这些动画。

## 与 PVZ1 的边界

PVZ1 保留在根项目，PVZ2 的代码、素材、依赖声明、测试和构建配置均在本目录。两者不导入对方的游戏逻辑、渲染器和资源，复用固定步长模拟、模型与渲染分离、按需加载、纹理预上传等设计。游戏之间通过页面跳转切换。

`pvz2-web:egypt1-complete` 保存首关通关记录，`pvz2-web:world-navigation` 保存世界选择及各地图浏览位置。不会读写 PVZ1 存档。

PVZ2 在 PVZ1 的 Service Worker 清单生成后才拼入发布目录，不参与一代离线下载；当前没有自己的 Service Worker。

## 运行与验证

在仓库根目录执行：

```sh
pnpm install
pnpm dev             # PVZ1 :5173；PVZ2 :5174，经 :5173/pvz2/ 代理访问
pnpm dev:pvz2        # 单独启动 PVZ2，访问 http://127.0.0.1:5174/pvz2/
pnpm test:pvz2
pnpm build:pvz2      # 独立输出 apps/pvz2/dist/
pnpm build           # 组合到 dist/ 与 dist/pvz2/
```

`pnpm test` 运行 PVZ1 测试。根目录 `pnpm preview` 预览组合构建。地图测试覆盖原始连线、解锁状态、浏览边界、动画资源引用及输出哈希；战斗测试保留原有十波通关与植物技能验证。

## 加载与后续接关

`src/shell/controller.ts` 管导航与 DOM 交互，`renderer.ts` 管独立动画时钟、相机和 Pixi 绘制，`navigation.ts` 管原地图节点状态与关卡路由。新增战斗入口时扩展 `LEVEL_ROUTES`，不要把战斗逻辑塞进地图渲染器。

首屏加载世界选择及共用 UI；进入世界后才请求该地图的 JSON、骨骼和 WebP 图集。骨骼两组并发加载并预上传纹理，离开地图释放其图集；远处的前景实例按可见范围创建和释放。音乐在首次交互时请求。原字体按当前外层文案提取为约 119 KB WOFF2，保持原字形。

13 个世界的外层资源合计约 43.6 MB（文件大小，含音乐，不含脚本和现有约 3.1 MB 战斗资源），不会一次全部下载。地图和首关战斗分别使用动画时钟；进入战斗时停止地图，返回时恢复。战斗代码与样式动态导入，样式限定在 `.battle-app` 内。

`src/game/` 和 `src/rendering/` 仍是现有战斗原型，包含四种植物、三种僵尸和十波敌人。固定四张卡、初始阳光、天空阳光、波次间隔、能量豆获取、部分特效和 HUD 尚未按原关卡完整还原。本轮没有扩展这些规则。

## 来源与可重复提取

来源：[PvZ2 Gardendless](https://github.com/Gzh0821/pvzge_web)，固定提交 `0e4a05348b6de328e2902a57afa24a3a454a4205`。从 Cocos 构建产物读取场景、嵌套预制体、属性覆盖与 DragonBones 资源，在独立应用中实现导航和渲染；无需运行其 Cocos、Bullet、Spine WASM，也没有还原原始 TypeScript 工程。

`asset-provenance.json` 与 `shell-provenance.json` 分别记录战斗和地图的输入／输出 SHA-256。`UPSTREAM-LICENSE` 保留仓库许可证文本，不代表对第三方美术、音乐另行授权。

```sh
# 战斗资源需要 Pillow；地图额外需要 fonttools 和 brotli。
python3 tools/pvz2-assets/extract.py
python3 tools/pvz2-assets/extract-shell.py
```

下载及纹理编码缓存放在忽略目录 `artifacts/pvz2-source/`。传送门引用普通关卡的两套光线子骨骼，提取时显式合并这一依赖；其余骨骼保留上游结构。字体子集取自世界名称、介绍和当前控制器文案，修改文案后重新执行地图提取脚本。
