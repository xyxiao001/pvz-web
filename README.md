# 植物大战僵尸 Web

用 TypeScript 和 PixiJS 构建的《植物大战僵尸》Web 移植项目，在浏览器中种植植物、收集阳光、守护庭院。

开放 50 个冒险关卡，包括僵王博士挑战；无尽生存模式覆盖白天、夜晚、泳池、迷雾和屋顶五种场景，支持暂停、保存与继续挑战。

支持原版风格六槽选卡、全部关卡开放开关、成就、倍速、阳光落地后自动收集、背景音乐和 2 倍高清素材。资源按需加载，可通过 PWA 安装到桌面，并缓存资源离线游玩。

**[在线游玩](https://pvz-web-khaki.vercel.app/)**

## 技术栈

| 技术 | 用途 |
| --- | --- |
| TypeScript | 游戏逻辑与交互 |
| PixiJS 8 | 2D 场景与动画渲染 |
| Vite 7 | 开发与构建 |
| HTML / CSS | 菜单与游戏 HUD |
| Web Audio API | 背景音乐与音效 |
| PWA / Service Worker | 应用安装与离线缓存 |
| Vercel | 网站部署 |
