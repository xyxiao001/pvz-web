# 植物大战僵尸 Web

用 TypeScript 和 PixiJS 构建的《植物大战僵尸》Web 移植项目，在浏览器中种植植物、收集阳光、守护庭院。

包含冒险关卡与无尽生存模式，覆盖白天、夜晚、泳池、迷雾和屋顶场景。支持六槽选卡、倍速、自动收集阳光、背景音乐，以及 PWA 安装体验。

**[在线游玩](https://pvz-web-khaki.vercel.app/)**

## 技术栈

| 技术 | 用途 |
| --- | --- |
| TypeScript | 游戏逻辑与交互 |
| PixiJS 8 | 2D 场景与动画渲染 |
| Vite 7 | 开发与构建 |
| HTML / CSS | 菜单与游戏 HUD |
| Web Audio API | 背景音乐与音效 |
| PWA / Service Worker | 应用安装与离线缓存 |
| Vercel | 网站部署 |
