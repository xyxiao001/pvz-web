# 植物大战僵尸 Web

TypeScript + PixiJS 8 + Vite 的本地可玩版本，以 PvZ-Portable 为行为参考。已实现原版素材主菜单、战斗 HUD、角色逐帧动画，以及可连续游玩的冒险 1–1 至 3–5，共 25 关。当前是玩法切片，不是 GOTY 全量移植。

## 运行

需要 Node.js 24 和 pnpm 11（工程固定 pnpm 11.0.9），npm 源在 `.npmrc` 中设为 https://registry.npmjs.org/ 。

```sh
pnpm install
pnpm dev
```

打开 http://127.0.0.1:5173/ 。

```sh
pnpm test     # 104 个测试，包含新增关卡的多种子正常操作通关
pnpm build    # TypeScript 检查与生产构建，产物在 dist/
pnpm preview # 本地预览生产构建
```

## Vercel 部署

根目录 `vercel.json` 配置 Vite 构建、`dist` 输出和 Service Worker 更新缓存头。导入 GitHub 仓库后使用 Node.js 24，安装固定版本 pnpm 并按锁文件安装依赖，再执行 `pnpm build`。不需要额外环境变量；部署到站点根目录。

## PWA 安装与离线

参考 KR 项目的构建期资源版本、启动文件预缓存、按需缓存与手动激活更新方案，已接入独立 manifest / Service Worker。主菜单 → 设置 → **安装与离线**：支持浏览器安装入口、完整资源下载进度、检查更新与主动重新加载。不会在战斗中自动刷新。

先 `pnpm build`，再 `pnpm preview`（默认 http://localhost:4173/）；当前已运行的生产预览是 http://127.0.0.1:5198/ 。开发服务器 5173 不注册 Service Worker。线上将 `dist/` 部署到站点根目录并使用 HTTPS；本地 localhost / 127.0.0.1 可测试，见 [MDN 安装条件](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable)。

首次离线前点击“下载离线资源”，等待 **离线资源已就绪**（约 135.3 MiB）。仅访问主界面并不代表所有关卡资源均已缓存。启动文件自动预缓存，高清素材 / 音效按访问缓存或一次下载；版本按文件内容散列，未变化资源复用。浏览器清除站点数据会清除缓存及本地存档，安装本身不跨浏览器转移进度。

图标包含 HTML favicon（16/32/ICO）、Apple Touch（180）、PWA（192/512）和 maskable（512），设计与复现说明见 [PWA.md](docs/PWA.md)。内置浏览器已验证真实停服后的离线重载、进入关卡和种植，以及手动更新；未实测 Chrome / iOS 系统安装界面。

## 四种场景的无尽生存

主菜单 → 无尽生存，可选择白天庭院、夜晚庭院、泳池和迷雾泳池。每轮 20 波，两面旗后保留防线、阳光、冷却和割草机，重新挑选六张卡。迷雾提供路灯花；水路先种睡莲，再放上层植物；缠绕海草直接种在空水面；白天的蘑菇会睡眠，咖啡豆尚未接入。

战斗中点“菜单” → “保存退出”，每个场景分别保存一局到当前浏览器。再次进入点“继续第 N 轮”，恢复为暂停状态，点“继续游戏”开战。轮间及选卡时也可保存。保存包括波次、实体、冷却、随机状态、倍速及自动收阳光设置；冒险解锁独立。旧无尽存档没有新增海草的冷却字段，本轮未做存档格式迁移；使用海草请新开该场景挑战。直接关闭页面不会自动保存。“新开一局”和“重新开始”清除该场景旧存档，失败时结束该局。

当前二十五关与四场景均使用 2× 资源，共 92 组 / 2425 帧、73 张静态图、6 张 4096² 图集，PNG 约 133.8 MiB，角色图集基础 RGBA 384 MiB。低显存设备尚未实测。舞王 / 伴舞、鸭子圈、潜水、寒冰菇、毁灭菇、睡莲、窝瓜、三线射手、路灯花、缠绕海草已接；巨人、屋顶及完整后期敌人池仍未接入，因此不是完整原版无尽。

104 项测试及生产构建通过。最近新增八关各有两个随机种子的正常操作通关；四种无尽场景各验证首轮两旗，并验证轮间重选和状态恢复。长时无尽难度尚未全面验证。后面的“本轮”“当前”小节保留旧阶段记录，以这里及源码基线末节为最新状态。

## 本轮性能和关卡迁移

- 移除每帧 HUD 节点查找，仅写入变化值；血条、格子提示与贴图帧仅在变化时更新。
- 移动在 10 ms 模拟状态之间插值；姿态帧、冷却、出怪共用游戏时间。暂停与主菜单停止 Pixi ticker。
- `src/game/data/portable-adventure.json` 保存提取数据、来源 commit 和文件哈希；`python3 tools/import-level-data.py PORTABLE_REPO` 可重建数据。`src/game/waves.ts` 迁移首次冒险预算、旗帜波、新僵尸引入与末波补齐逻辑。
- 原版并不存在唯一固定的出怪清单。仍使用本项目 LCG，不能保证与原版相同种子逐只一致；没有把完整教程、Reanim 或其他模式宣称为已移植。
- 本机浏览器同场景短测（45 植物 / 30 僵尸 / 20 豌豆 / 10 阳光），更新与绘制提交 CPU 均值约 0.446 → 0.253 ms，P95 约 0.8 → 0.4 ms；360 帧的 HUD DOM 变更 3246 → 375。此数据衡量特定场景 CPU 开销，不是全设备帧率保证，也不包含 GPU 完成时间。

## 2 倍高清素材

目前 1–1 至 2–4、主菜单、六槽选卡和传送带统一使用 `public/assets/hd/`。原图保留在原路径，运行时直接加载高清资源，没有自动切回原图的分支。背景、HUD、卡片、植物与僵尸使用 Real-ESRGAN 的 `realesr-animevideov3-x2` 离线超分；浏览器只加载普通 PNG，不运行 AI。

- 当前共 52 组、1426 帧，时长、锚点、逻辑尺寸和碰撞保持原值。1370 张不同帧分别超分再打包，避免相邻图集图片影响推理。
- Pixi 纹理使用 `resolution: 2`，物理像素翻倍而角色显示大小不变。画布根据显示宽度和设备像素比设置实际渲染分辨率，世界坐标仍为 800×600。
- 50 张静态图及 4 张角色图集约 79.4 MiB PNG。角色纹理基础 RGBA 占用为 256 MiB（夜晚接入前为 192 MiB），不含背景、浏览器解码副本及渲染缓冲。低显存设备表现尚未验证。
- 这是超分增强，保留原画风，不是新发现的原生高清素材，也不会提升原 GIF 的动作采样率。

生成信息、输入散列与模型散列见 [高清资源清单](public/assets/hd/manifest.json)。复现需要 Pillow，以及 [Real-ESRGAN 官方 20220424 ncnn-vulkan 发行包](https://github.com/xinntao/Real-ESRGAN/releases/tag/v0.2.5.0) 中的可执行文件与 models 文件夹：

