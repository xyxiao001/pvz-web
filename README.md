# 植物大战僵尸 Web

在浏览器里种下向日葵，搭起防线，迎接下一波僵尸。

基于 TypeScript 与 PixiJS 的《植物大战僵尸》Web 移植项目。现已开放 50 个冒险关卡，包含保龄球、打僵尸、砸罐子、雷雨之夜与僵王战；白天、夜晚、泳池、迷雾、屋顶五种场景均可挑战普通、困难和无尽生存。项目仍在持续移植与完善。

**[开始游戏 →](https://pvz-web-khaki.vercel.app/)**

- 冒险六槽选卡、生存最多十槽选卡，支持升级植物与轮间换卡。
- 生存模式可暂停、保存退出，按场景和难度分别继续挑战。
- 支持倍速、阳光落地后自动收集、可选僵尸血条、背景音乐和成就。
- 原版素材与 HUD 风格，角色部件插值动画、动态火豌豆、按需加载。
- 支持电脑与手机横屏，可通过 PWA 安装并下载离线资源。

## 并行的 PVZ2 应用

独立应用 [`apps/pvz2`](apps/pvz2/README.md) 已接入神秘埃及、海盗港湾、狂野西部、遥远未来各 35 个主线关卡，以及黑暗时代 1–25 关。各批验证情况和还原差异见 [迁移记录](apps/pvz2/FIDELITY.md)。PVZ1 主菜单可切换到 `/pvz2/`，PVZ2 可返回经典一代；两者分别维护代码、素材、存档和构建，只沿用架构与加载优化方案。

`pnpm dev` 同时启动两者，`pnpm build` 分别构建后组合发布目录；`pnpm dev:pvz1`、`pnpm dev:pvz2` 可单独开发。PVZ2 测试运行 `pnpm test:pvz2`，PVZ1 原有测试命令不变。

两版均支持独立 PWA 安装、离线资源下载和手动更新。PVZ2 入口为“设置 → 安装与更新”，应用标识、缓存和更新与 PVZ1 分开；生产构建启用，开发模式不注册 Service Worker。详见 [PWA 使用与验证说明](docs/PWA.md)。

## 技术栈

| 技术 | 用途 |
| --- | --- |
| TypeScript | 游戏规则、固定步长模拟与交互 |
| PixiJS 8 | 2D 场景、部件动画与特效 |
| Vite 7 | 开发服务与生产构建 |
| HTML / CSS | 游戏菜单、选卡与 HUD |
| Web Audio API | 背景音乐与音效 |
| Service Worker / PWA | 安装、离线缓存与更新 |
| Vercel | 网站部署 |
